# Vivid Karma — java Stats Cli

A dependency-free java CLI that computes count, sum, mean, min and max — with readable source, run instructions and sample output, presented as a polished static report.

## Features

- Written in java
- zero dependencies, single file
- deterministic sample output
- run instructions for javac Main.java && java Main
- polished static documentation page
- English/German interface

## Local development

```bash
git clone https://github.com/ruslanfridenli/vivid-karma.git
cd vivid-karma
# open index.html in a browser, or serve statically:
npx serve .
```

No build step, no dependencies — pure static site.
